记账本 · 桌面版（Windows 原生程序）
====================================

这是一个真正的 Windows 桌面程序，用 .NET 8 + WPF 写成。
不是网页套壳，没有内置浏览器，不联网，不开后台服务。


一、怎么启动
------------

双击 MoneyTracker.exe 就行。

首次启动会自己建好数据文件，直接就能记账。

（程序名是英文的 MoneyTracker，是为了让路径和杀毒软件都省心；
在开始菜单、任务栏和窗口标题里显示的都是"记账本"。）


二、数据存在哪
--------------

数据文件就在程序旁边的 data 文件夹里：

    记账本.exe 所在的这个文件夹
    MoneyTracker.exe      <- 程序本体，双击它
    data\db.json          <- 你的全部记录都在这一个文件里
    data\db.json.bak      <- 自动留的上一次备份
    data\backups\         <- 程序内备份的快照（见"十三、备份与回档"）

想换电脑，把整个文件夹拷走就行；想删干净，把文件夹删掉就行。
程序不会往别的地方写任何东西，也不碰注册表。

这个 exe 是自包含的：里面已经带了整个 .NET 运行时。
拷到别的 Windows 电脑上直接双击就能开，不需要先装 .NET、
不需要 Node、不需要任何别的东西。一句话，只有一个文件，
没有依赖，走到哪都能跑。


三、六个页面
------------

记账     输金额、选分类、保存。数字键盘可以一直点着输。
明细     看记录、筛选、改、删，导出的地方也在这。
报表     分类占比、排行、每月对比、结余走势、各账本盈亏比较。
预算     给分类设上限，看还剩多少、还能花几天。
分析     自动读你的流水，给出这个月值得看的发现。
设置     换主题、导数据、管规则、管账户、管分类。

侧边栏上方是账本，点一下就在几个人之间切换（见第十五节）。
账户管理和分类管理是从设置页点开的独立窗口。


四、记一笔有多快
----------------

1. 点数字键输金额
2. 点一个分类（比如"餐饮"）
3. 点"记下这笔"

就这样，三下。

想连着记好几笔，用"保存并再来一笔"。
键盘党可以用回车直接存。

分类会按你输的商户名自动判断（比如输入"美团"会自动归到餐饮/外卖），
这套判断规则可以在设置里改，也可以自己加。


五、从账单导入（CSV）
---------------------

支持三种：

1. 支付宝账单    「交易创建时间」「交易对方」「收/支」那一套
2. 微信支付账单  「交易时间」「交易对方」「当前状态」那一套
3. 普通 CSV      任何表格导出的都行，只要有日期和金额两列

怎么操作：
设置 → 数据导入导出 → 选文件（可以一次选多个）
或者选文件夹，里面所有 csv 会一起导进来。

它会自动做这些事：
  · 编码自动认（UTF-8、带 BOM、GBK 都能读，支付宝微信导出的默认就是 GBK）
  · 表头按列名找，不要求列的顺序
  · 「不计收支」的记录跳过
  · 退款、交易关闭、未支付的记录跳过
  · 重复的记录自动去重（同一天、同金额、同商户、同账户）
  · 商户名拿去和你的自动记账规则对，直接分好类
  · 支付方式能对上账户名就归到那个账户

导完会告诉你：新进了几笔、跳过几笔、重复几笔、为什么跳过。
不会闷头导一堆垃圾进来。


六、导出
--------

三个地方都能导，按钮都摆在明面上：

  明细页  →  导出 Excel / 导出 Word / 导出 CSV / 整库备份 JSON
  报表页  →  导出报表 Excel / Word / CSV
  设置页  →  一样的四个按钮

导出来的东西：

  Excel (.xlsx)   五个工作表：明细、分类汇总、月度汇总、账户流水、账户余额
                  用 Excel 或 WPS 直接打开，格式是标准 OOXML
  Word (.docx)    一份排好版的报表：总览、分类排行、分类占比、月度走势、
                  账户概览、全部明细，带表格和分页，能直接打印
  CSV (.csv)      一行一笔，带 UTF-8 BOM，用 Excel 打开不乱码
  JSON (.json)    整库备份，包含记录、账户、规则、预算、设置

导出的范围跟着明细页的筛选走——筛了哪个月就导哪个月。


七、换主题
----------

设置 → 外观主题，内置七套：

  浅色     干净的默认配色，白天用最舒服
  深色     夜间记账不刺眼
  护眼绿   低饱和绿底，长时间看着不累
  午夜蓝   深蓝夜色，偏冷
  暖阳     米黄暖调，像纸一样
  樱花粉   粉嫩一点，也可以很认真
  高对比   黑底亮黄，视力不好也能看清

点一下就换，不用重启。

不喜欢主题自带的颜色，还能只换强调色：
八个预设（天蓝、青绿、紫罗兰、橘橙、玫红、正红、石墨）任选，
或者直接填一个 #RRGGBB 色号。
按钮、选中项、图表的主色都会跟着变。

还能单独换字体，五套可选，点一下立刻生效：

  细雅黑   笔画细一些，长时间看着不累（默认）
  标准雅黑  Windows 最常见的观感，字迹最清楚
  等线     更方正，字面干净
  圆润     圆头圆脑，最软的一种
  楷体     像手写，偏文艺（数字会不太整齐）

觉得字太小或太大，下面的「整体字号」能从 85% 拉到 125%。

还能给自己的程序铺一张背景图：

  设置 → 外观主题 → 自定义背景图 → 选择图片

挑一张图（jpg / png / bmp / gif / webp / tif 都行），程序会自动
把图缩小再模糊，所以再大的图也不会拖慢速度。侧边栏保持实色，
只有内容区透出背景，文字始终清楚。

两个滑块随便调：
  模糊程度   0 到 60，15 到 25 之间一般最舒服，调太大就看不出是什么图了
  淡出程度   0 到 95，往右拉背景越淡、字越清楚，觉得图太抢戏就往右拉

不满意点「不用背景图」就撤掉，随时可以换。
背景图这个设置只记路径，不复制图片，所以你原来的图放哪都行；
哪天图被你删了或移动了，程序会自动当没有背景图处理，不会报错。

另外可以单独设：
  · 支出用红色、收入用绿色（不勾就都按主题色来）
  · 货币符号（默认 ¥，也能填 $、€ 或别的）


八、预算
--------

设置 → 预算页 → 新增一项预算，选分类，填上限。

有个"按上三月均摊"的按钮：程序会算最近三个月的实际平均花销，
一键把所有分类的预算都填上，省得你一个个想。

每月会告诉你：
  · 这个分类还剩多少
  · 按现在的花法，到月底够不够
  · 总预算还剩几天可花


九、智能分析
------------

分析页会把你的流水读一遍，给出这个月值得看的发现，比如：

  · 比上个月多花/少花了多少
  · 储蓄率是多少（健康区间 20%~30%）
  · 钱主要花在哪个分类上，占多大比例
  · 最大的一笔是哪笔
  · 常去的商户是哪几家
  · 工作日和周末的花法有什么不一样
  · 哪个分类这个月涨得猛
  · 有没有疑似在自动扣费的订阅
  · 照这个速度月底会花多少
  · 想省钱的话，最该动哪一块

每一条写的都是你自己的真实数字，不是套话。


十、快捷键
----------

Alt+1  记账
Alt+2  明细
Alt+3  报表
Alt+4  预算
Alt+5  分析
Alt+6  设置

记账页：输入框里按回车 = 保存
明细页：双击一行 = 改它，右键 = 更多操作


十一、账户
----------

预置了五个：现金、微信、支付宝、招商银行、信用卡。
可以在设置里改名字、加新的、填初始余额。

每个账户可以单独决定算不算进净资产（信用卡这类就别算）。
改了账户名，历史记录里的名字会跟着改，余额不会断。

账户页把账户分了组，一层一层看：

    分组   自己 / 家人 / 他人 / 工作，也可以自己填新的（比如「朋友」）
    类型   现金 / 电子钱包 / 银行卡 / 信用卡 / 投资 / 其他
    账户   最底下那一层

分组名是随便写的，不限于预置那几个。左边的树会让每个分组、
每种类型都显示自己的小计和个数，下面还有合计，和明细页对得上。

账户页抬头写着「我的资产」「他人账户」「垫付未还」三个数，
旁边能选统计口径（本月 / 近 3 个月 / 今年 / 全部时间……）。

    支出、收入、垫付、账户后面那个「花」   按当前账本算，跟明细页完全一致
    余额、我的资产、他人账户             把所有账本合起来算

一本账的时候这两套本来就是同一个数，所以不解释；
多账本时才会碰上「为什么这里的数跟那里不一样」，那时候页面副标题会写明。

另外还能给账户标「归属人」（比如「妈妈的银行卡」）和「这是别人的账户」，
别人的账户不计进你的净资产，己方那边也会单独算。

信用卡这种欠钱的账户会显示成负数，一眼能看出是欠着的。

账户删了以后，它历史上记过的账不会跟着消失，会单独归到一块「未归类」里——
这样各组合计加起来才跟总数对得上。

老数据不用管，group 是空的账户会自动落进「自己」，
老的类型叫法（cash / wallet / debit / credit / investment）也照样认。


十二、替别人花的钱，怎么记
----------------------------

有些钱不是给自己花的：帮同事垫了饭钱、替家里交了水电。
这种别记在自己头上，记账的时候有两个地方可以写：

    替谁花的（可以不填）   写个名字，常用过的名字会变成快捷按钮
    垫付：这笔钱对方该还我  勾上，这笔就记成对方欠你的

勾垫付只在支出的时候出现，切到收入或者转账会自动取消。

不填也完全不影响记账，这两项都是可选的。

记完之后：

    明细页   多了一列「垫付」，写着「垫 · 张三」或者「垫 · 李四（已还）」
    明细页   有一张「垫付未还」的汇总卡
    明细页   能按 全部 / 只看垫付 / 只看未还 / 只看已还 筛
    明细页   右键某一条（选中的几条也一起），标记为已还、或者取消已还标记
    账户页   右边有一张「替谁花了多少 · 谁欠我多少」

账户页那张卡是每人一行，按「还欠多的排前面、其次是花得多的」排。
每行是：名字 ｜ 一共替他花了多少 · 几笔 ｜ 还欠多少（没欠就写「没欠了」）｜ 状态。

    状态行     「2 笔还没还」/「已还清 2 笔（¥244.00）」/「没标成垫付」
    按钮       还没还清就是「已还清」，已经还清了就变成「撤销已还」，一行上只有一个

卡的抬头写着「还欠合计 ¥274.00」和「一共替别人花了 ¥344.00，涉及 4 个人
（其中 2 个人还欠着）」。

只写了名字、没勾垫付的人也在这个列表里，显示「没标成垫付」；
勾了垫付却忘了写名字的会归到「没写名字」，不会漏掉一笔。

两个地方改的是同一批记录：

    账户页   「已还清」= 把这个人的垫付一次全部标成已还，会先问你一句
    账户页   「撤销已还」= 把这个人的标记整体退回未还，也会问一句
    明细页   单笔的勾和撤，配合「只看未还」可以一条一条点

点完两边立刻同步，不用手动刷新。

注意两件事：
一是勾「已还清」不会自动替你记一笔收入。
钱要是收进了哪个账户，去「记一笔」自己记条收入，账才对得上。
自动猜账户反而容易把账弄乱，所以这里不猜。
二是「替谁花了多少」这两个数是累计的，不跟着上面的月份走——
欠款一会儿变一会儿不变会让人以为算错了。

口径说清楚：垫付和账户上的「花」是按当前账本算的（跟明细页一致），
而账户余额、「我的资产」、「他人账户」是把所有账本合起来算的
（钱是实体资产，不该按账本切）。只有一个账本时，这两套口径本来就一样。


十三、分类完全由你自己定
------------------------

预置的那套分类只是给你开个头，不是写死的。想加个「生活费」，随时都能加。

设置 → 分类 → 打开分类管理。里面能对一级分类和二级分类做这些事：

    添加     加一个全新的一级分类，或者给某个分类加细分
    改名     改完之后，已经记过的账会跟着一起改
    删除     删之前会告诉你有多少笔在用；这些记录会转到「其他」，不会丢
    ↑ ↓      调顺序，常用的挪到前面

改名字这条多说一句。以前改个分类名，老记录会挂在一个
已经不存在的名字上，等于把自己的账改乱了。现在的做法是：你点保存时，
程序会把所有还写着旧名字的记录一次性改过来，还会告诉你顺手改了多少处。
所以想改就放心改，不用一条条手动修。

嫌自己改乱了，底部有「恢复出厂分类」，一键回到刚装好的样子
（你自己加的那些会没掉，但记录不会丢，只是挂回默认分类上）。


十四、一级分类下面还能再分细一层
--------------------------------

每个一级分类下面都能再挂一层二级分类，比如：

    餐饮 -> 外卖 / 早餐 / 午餐 / 晚餐 / 咖啡奶茶 / 聚餐 / 买菜 / 其他
    购物 -> 日用品 / 服饰 / 数码 / 美妆 / 其他
    交通 -> 打车 / 公交地铁 / 加油 / 停车 / 其他

这些都归上面那个分类管理管，名字随便改，不满意就换。

怎么用：

    1. 先点上面的一级分类（比如"餐饮"）
    2. 下面会展开两行："常用"一行，和"「餐饮」下面这些"一行
    3. 点一下选中，再点一下取消

二级分类可以不选，留空照样能记账，不会拦你。

猜不出该选什么也没关系：直接点"常用"里你以前用过最多的那几个，
或者自己在下方的输入框里打一个新词——打过一次，下次它就会
自动出现在按钮里。

明细页可以按二级分类筛，表格里也是独立一列，
所以"餐饮一共花了多少"和"其中外卖花了多少"能分得清清楚楚。


十五、几个人一起用：一人一本账
--------------------------------

同一个程序里可以放好几本账，各记各的，互不掺和。

左边侧边栏有个账本区，列出全部账本（色点 + 名字 + 笔数），
点一下就切过去，正在看的那本会高亮打勾。顶上还会显示
"账本「我」· N 笔记录"，一眼知道现在看的是哪本。

想单独管账本，点边上的「管理」：

    新建账本     起个名字、挑个颜色、写句备注（比如"两个人的共同开销"）
    改名换色     名字随便改，颜色有 10 个现成的，也能直接填 #RRGGBB
    归档         不常用但不想删的，收起来，列表里还能看到
    删除         要么指定记录转给哪本，要么明确勾选"连记录一起删"
                 最后一个账本永远删不掉，防止手滑删空

切换账本之后，记账、明细、报表、预算、分析、导入、示例
全都只看当前这本，不会串到别的账上去。

想对比几本账：侧边栏点「盈亏对比」，或者到报表页往下翻，
有个「各账本盈亏比较」卡。每本一行，显示收入和支出，底下有合计行，
点某一行可以直接切到那本账。

关于去重，这里有个以前会丢数据的坑：同一本账里，同一天同一笔钱
不会重复计入；但两本账各记一笔一模一样的，互不影响。

另外说明一下，净资产和账户余额是全部账本合计的——账户本来就是
多本账共用的（比如"现金"这个账户，哪本账都在用）。
状态栏那个数字把鼠标放上去会说明这一点。


十六、备份与回档
----------------

设置 → 数据导入导出 → 备份与回档。

这是程序自带的"存档 / 读档"，不用你自己导出文件：

  立即备份     现在存一个档，起个说明（默认"手动备份"）
  回档到这个   把数据整个退回那一刻的样子
  删除         删掉某一个快照
  清理旧的     只保留最近 N 个，其余删掉

什么时候用得上：

  · 记账记错了、改乱了，想退回去
  · 导入账单之后发现重复了一大堆，想反悔
  · 手滑清空了记录
  · 想看看"上个月这时候我账上是什么样"

放心的一点：回档之前，程序一定会先自动存一份
"回档前自动备份"。所以回档这件事本身也能反悔，
点错了再回档到那一份就行。

快照放在 data\backups\ 里，一个快照就是一个 json 文件，
内容跟 db.json 完全一样，所以拷出去也能直接当整库备份用。

快照会占地方（每个大概是 db.json 那么大），
攒太多了用"清理旧的"收一下就行。


十七、彻底删掉
--------------

把程序所在的整个文件夹删掉就行。
没有服务、没有自启项、没有注册表、没有写在别处的文件。


十八、技术说明
--------------

.NET 8 + WPF，不依赖任何第三方库。
Excel 和 Word 文件是程序自己按 OOXML 标准写出来的，
所以不需要装 Office 也能导出（只是要看的话得有 Office 或 WPS）。
